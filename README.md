# 四象限待办（QuadrantTodo）

一款基于 **Python + PySide6 + SQLite** 的 Windows 桌面待办工具。核心理念是**象限由系统自动计算，而不是手动分类**：用户只维护「是否重要」和「截止日期」，象限归属由系统按规则推导，任务会随时间自动跨象限迁移（例如「重要不紧急」临近截止时自动变成「重要且紧急」）。

- 当前版本：**v1.2.2**
- 技术栈：Python 3.9+ / PySide6（唯一外部依赖）/ SQLite 3（标准库 `sqlite3`）
- 界面主题：浅色 / 深色，自动跟随系统
- 运行形态：常驻系统托盘的单实例桌面应用，全程离线、无需注册账号
- 开源协议：[MIT](LICENSE)

## 功能特性

| 模块 | 说明 |
| ---- | ---- |
| 四象限看板 | 主视图（Ctrl+1）。象限底部直接输入标题创建任务，象限由系统算出；支持**拖拽改属性**（拖到紧急区 = 截止日期设为今天，拖到重要区 = 标记为重要），确认框可「锁定到此象限」手动固定。任务随时间自动跨象限迁移。象限右上角显示「**共 N 条**」 |
| 日 / 周 / 月 / 年待办 | 日待办 = 截止日期为今天或已逾期 + 已加入今日的任务；周 / 月 / 年按截止日期范围筛选。四个视图统一用顶部 **Q1–Q4 四个页签**分组，页签显示各象限任务数，空象限显示 `(0)` 且始终可见，切换视图会记住上次所在页签 |
| 待安排 | 汇总所有没有截止日期的任务，可批量补充截止日期，缓解「无截止日期任务长期堆积」问题 |
| 日历视图 | 月历形式查看每天的任务分布 |
| 人生热力图 | 一年 365 格活动密度图，记录全部完成活动（含无截止日期任务），支持按年切换 |
| 任务详情 | 标题、截止日期、计划日、提醒、备注、标签、子任务均可即时修改 |
| 标题智能识别 | 输入标题中的日期（如「周五交报告」）自动识别为截止日期 |
| 子任务 / 清单 | 独立清单挂靠任务并显示进度；**子任务全完成不自动完成父任务**，由用户决定 |
| 标签 | 多标签，可按标签筛选任务列表 |
| 周期任务 | 按日 / 周 / 月 / 自定义 RRULE 规则重复；完成后**原地重置到下一周期**，历史完成写入不可变的 `task_completion` 表，热力图与统计不因重置而丢失 |
| 提醒 | 详情面板设置具体时间，到点弹系统通知 + 托盘闪烁；休眠错过的提醒恢复后补发并标注逾期时长；新建提醒默认取当天「下一整点」 |
| 番茄钟 | 默认 25 分钟（设置中可调 5–60 分钟），计时统计可查看 |
| 任务搜索 | 关键词 + 标签 + 范围组合搜索，默认排除已完成，可勾选找回 |
| 小便签 | 浮层 + 列表双形态的随手便签（Ctrl+Enter 快速创建），支持**锁定防误删**、**最大化独立窗口**、**常驻默认在屏幕最右侧**（多便签时依次向左错开） |
| 文章 | 独立内容模块（Ctrl+8）。正文支持 Markdown 语法，可一键「编辑 / 预览」切换查看渲染效果（纯标准库实现，不引入第三方 Markdown 库）；标题 / 正文自动保存，带标签与全文搜索 |
| 系统级全局热键 | 应用未聚焦也生效，基于 ctypes / Win32 `RegisterHotKey` 自实现，零第三方依赖；需在设置中开启，默认关闭 |
| 数据与备份 | SQLite 启用 WAL；**可配置自动备份**（开关 / 频率 1–30 天 / 时刻 / 保留份数 1–100），默认每天 20:00 备份一次、同天覆盖、保留 7 天；支持 JSON 导入导出（覆盖任务、子任务、标签、番茄钟、便签、完成历史） |
| 系统托盘 | 关闭窗口不退出，进程常驻；右键托盘可打开主窗口 / 快速添加 / 设置 / 退出 |

## 运行环境

- Windows 10 / 11（64 位）
- Python 3.9+（开发 / 从源码运行需要；使用打包版 exe 无需安装 Python）

## 安装与运行

### 方式一：直接使用打包版（推荐）

解压 `QuadrantTodo_v1.2.2.zip` 后双击 `QuadrantTodo.exe` 即可，无需安装。

数据文件默认放在 **exe 同目录**（便携模式）：

```
data.db / data.db-wal / data.db-shm
backups\    （自动备份）
logs\       （运行日志）
```

如需放到别的位置：设置环境变量 `QUADRANT_DATA_DIR` 可重定向，或在「设置 - 数据」中修改数据目录（会自动迁移文件）。

### 方式二：从源码运行

```bat
:: 1. 进入项目目录
cd todolist

:: 2. （推荐）创建虚拟环境
python -m venv venv
venv\Scripts\activate

:: 3. 安装依赖（PySide6 是唯一外部依赖）
pip install -r requirements.txt

:: 4. 启动程序
python -m quadrant_todo.main
```

> 首次启动会自动创建数据库（schema 自动初始化到最新版本）。

### 打包为 exe（可选）

```bat
python build.py
```

使用 PyInstaller `--onedir`（单目录）模式产出免安装目录并自动压缩为 zip。选择单目录而非单文件的原因：`--onefile` 每次启动都需解压，在 PySide6 的体积下启动明显偏慢。

日常纯代码更新**只需替换 `QuadrantTodo.exe`**（应用代码嵌在 exe 内部的 PYZ 归档中），`_internal\`、`data.db`、`backups\`、`logs\` 均无需改动。

## 使用说明

1. **四象限看板（Ctrl+1）**：在象限底部输入框输入标题回车即可创建。你只需要标记「重要」和填「截止日期」，象限由系统算。拖动任务到另一个象限即修改属性。
2. **日待办（Ctrl+2）**：今天要执行的任务，按 Q1–Q4 四个页签分组，与四象限数据同源唯一。
3. **周 / 月 / 年待办（Ctrl+3 / 4 / 5）**：按截止日期范围筛选，同样用四个页签分组。
4. **日历（Ctrl+6）/ 热力图（Ctrl+7）**：查看任务时间分布与年度活动密度。
5. **待安排 / 搜索（Ctrl+F）/ 便签**：处理无截止日期任务、组合条件查找任务、记录随手内容。
6. **设置（Ctrl+,）**：紧急阈值（按重要性分别设置）、番茄钟时长、全局热键、自动备份策略、开机自启、数据导入导出与目录修改。

## 象限判定说明

象限**不落库**，是 `importance + due_date` 的派生值，每次读取时计算（`quadrant.py` 为无状态纯函数，可 100% 单测覆盖）。

- **重要性**：用户手动标记（重要 / 不重要）。
- **紧急性**：由截止日期自动推导 —— 无截止日期 → 不紧急；已逾期 → 紧急（强制）；剩余天数 ≤ 阈值 → 紧急；其余 → 不紧急。
- **象限映射**：

| | 紧急 | 不紧急 |
| ---- | ---- | ---- |
| **重要** | Q1 重要且紧急 | Q2 重要不紧急 |
| **不重要** | Q3 紧急不重要 | Q4 不重要不紧急 |

- **双阈值**：重要任务与不重要任务的紧急窗口可分别设置（默认均为 2 天，可选 1 / 2 / 3 / 7 天），对应控制 Q1↔Q2 与 Q3↔Q4 的边界。
- **锁定例外**：任务可被显式锁定到某个象限（`locked_quadrant`），锁定后不再迁移；当锁定结果与规则推算不一致时，界面提示「建议移至 Qx」。

> **设计红线**：象限入口创建任务时不锁定象限（只决定 `importance`）。任何「创建即锁定」的规则都会让任务永不迁移，废掉自动迁移这一核心价值。
>
> **统计口径**：完成率等指标**只统计有截止日期的任务**（分子分母均不含无截止日期任务），另外单独显示「待安排 N 条」。

## 常见问题

- **关闭窗口后程序没退出**：这是预期行为。应用常驻系统托盘，点击窗口关闭按钮（×）仅隐藏窗口；彻底退出请右键托盘图标选择「退出」。
- **重复启动没反应**：单实例运行（`QLocalServer` 判重），重复启动会唤起已有窗口，避免 SQLite 写冲突。
- **界面主题**：固定跟随系统深浅色，设置中无手动切换入口。
- **数据备份与迁移**：默认每天 20:00 自动备份到 `backups\`，按日期命名（`data_YYYYMMDD.db`）、同天覆盖、保留最近 7 天；可在「设置 - 数据」调整或点「立即备份」。迁移到新机器时直接复制 `data.db` 即可。
- **更换数据目录**：在「设置 - 数据」中修改会自动迁移文件；也可用环境变量 `QUADRANT_DATA_DIR` 重定向。
- **界面乱码**：程序使用中文字体，若系统缺少中文字体请安装。
- **打包后没有 `.pyc` 文件**：这是正常的。PyInstaller 把应用代码编译进 exe 内部的 PYZ 归档，不会在 `_internal` 下展开源码，因此不能用「有没有 .pyc」判断产物是否完整——需要实际运行验证。
