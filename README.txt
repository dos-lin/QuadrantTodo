四象限待办 QuadrantTodo — 使用说明
====================================

一款基于艾森豪威尔矩阵（重要 × 紧急）的桌面待办工具。任务的象限
由系统根据「是否重要 + 截止日期」自动计算，无需手动分类；随着时间
推移，任务会自动从一个象限迁移到另一个象限（例如「重要不紧急」的
任务临近截止时会自动变成「重要且紧急」）。

技术栈：纯 Python + PySide6 + SQLite（PySide6 为唯一外部依赖）。
当前版本：1.0.0（涵盖一期 MVP 与二期全部功能）。

一、启动与退出
--------------
解压后双击 QuadrantTodo.exe 即可，无需安装。首次启动默认全屏。
数据文件默认放在 exe 同目录（便携模式）：
    data.db / data.db-wal / data.db-shm
    backups\    （自动备份）
    logs\       （运行日志）
如需放到别的位置：环境变量 QUADRANT_DATA_DIR 可重定向，
或在「设置 - 数据」中修改数据目录（会自动迁移文件）。

关闭窗口不会退出程序，应用常驻系统托盘，可随时从托盘快速添加任务。
右键托盘图标可打开主窗口 / 快速添加 / 设置 / 退出。
点击窗口关闭按钮（×）仅隐藏窗口；彻底退出请右键托盘选择「退出」。
主题自动跟随系统深浅色，无需手动设置。

二、视图总览（Ctrl+1 ~ Ctrl+7 切换）
------------------------------------
- 四象限看板（Ctrl+1）：主视图。象限底部「+ 添加任务」输入标题即可
  创建，象限由系统算出来。拖动任务到另一个象限 = 修改属性
  （拖到紧急区 = 截止日期设为今天；拖到重要区 = 标记为重要），
  确认框中可「锁定到此象限」手动固定。
- 日待办（Ctrl+2）：今天要执行的任务（截止日期为今天或已逾期 +
  已加入今日），按象限分组，与四象限数据同源。
- 周待办（Ctrl+3）/ 月待办（Ctrl+4）/ 年待办（Ctrl+5）：
  按截止日期范围筛选的时段视图。
- 日历（Ctrl+6）：月历形式查看每天的任务分布。
- 人生热力图（Ctrl+7）：一年 365 格活动密度图，记录全部完成活动
  （含无截止日期任务），可按年切换。
- 待安排：所有没有截止日期的任务。点击可批量补充截止日期。
- 搜索（Ctrl+F）：关键词 + 标签 + 范围组合搜索，默认排除已完成，
  可勾选找回已完成任务。
- 便签：浮层 + 列表双形态的随手小便签（Ctrl+Enter 快速创建）。

三、任务功能
------------
- 详情面板：点任务查看。标题、截止日期、计划日、提醒、备注、
  标签、子任务均可即时修改。
- 标题智能识别：输入标题中的日期（如「周五交报告」）可自动识别
  为截止日期。
- 子任务 / 清单：独立清单挂靠任务，显示进度；子任务全完成
  不会自动完成父任务。
- 标签：多标签，可按标签筛选任务列表。
- 周期任务：按日 / 周 / 月 / 自定义规则重复，完成后自动重置到
  下一周期（历史完成记录永久保留，热力图与统计不受影响）。
  注意：入口处「周期」字段当前版本仍标注「敬请期待」，
  周期功能在任务详情中配置。
- 提醒：详情面板设置具体时间，到点弹系统通知并闪烁托盘；
  休眠错过的提醒恢复后会补发并标注逾期时长。
  新建提醒默认取当天「下一整点」。
- 番茄钟：选中任务点「开始」进入进行中状态后可开番茄钟计时，
  默认 25 分钟（设置中可调 5–60 分钟），计时统计可查看。

四、快捷键
----------
Ctrl+N 快速添加      Ctrl+1 四象限        Ctrl+2 日待办
Ctrl+3 周待办        Ctrl+4 月待办        Ctrl+5 年待办
Ctrl+6 日历          Ctrl+7 热力图        Ctrl+F 搜索
Ctrl+, 设置          Ctrl+Q 退出
↑/↓ 切换任务         Space 完成/取消      Enter 编辑标题
F2 重命名            Delete 删除          Esc 取消选择/关闭输入框

系统级全局热键（应用未聚焦也生效，默认关闭，设置中开启）：
- 显示/隐藏主窗口：默认 Ctrl+Alt+Q
- 全局快速添加：默认 Ctrl+Alt+N
格式需含至少一个修饰键（Ctrl/Alt/Shift/Win），避免劫持普通按键。

五、数据与备份
--------------
默认每天 20:00 自动备份到 backups\，同一天多次退出只覆盖当天那份
（按日期命名 data_YYYYMMDD.db），保留最近 7 天。
可在「设置 - 数据」调整：自动备份开关、备份频率（1–30 天）、
备份时刻、保留份数（1–100 份），或点「立即备份」手动执行。
退出时若距上次备份已达间隔天数，也会补偿备份一次。
可在「设置 - 数据」中导出 / 导入 JSON（覆盖任务、子任务、标签、
番茄钟、便签、完成历史等全部数据）、修改数据目录、打开数据目录。
SQLite 启用 WAL 模式，单实例运行（重复启动会唤起已有窗口）。

六、设置项速览
--------------
- 紧急阈值：按重要性分别设置（重要任务 / 普通任务各一个阈值），
  截止日期剩余天数不超过阈值时判定为「紧急」。
- 番茄钟时长：默认 25 分钟，可调 5–60 分钟。
- 全局热键：开关 + 两组按键自定义。
- 自动备份：开关 + 频率（1–30 天）+ 时刻 + 保留份数（1–100）+ 立即备份。
- 开机自动启动：默认关闭。

七、已实现功能范围
------------------
一期（MVP v1.3）：四象限看板、日待办、待安排、任务详情、桌面通知、
系统托盘常驻、跨日自动重算、本地数据与备份、单实例、窗口状态记忆、
快捷键、标题智能识别截止日期。

二期 v2.0：周/月/年待办、周期任务启用、日历视图、提醒联动、
深浅色主题（跟随系统）。

二期 v2.1：子任务/清单、标签、任务搜索、人生热力图、小便签、
番茄钟/计时统计、系统级全局热键，以及 12 项 UI/UX 体验细化
（双紧急阈值、详情面板滚动、空象限不塌陷、进行中任务标红等）。

未实现（后续规划）：云端同步、移动端。

八、从源码构建
--------------
    python -m pip install -r requirements.txt
    python build.py        # PyInstaller --onedir，产出免安装单目录

日常纯代码更新只需替换 QuadrantTodo.exe（应用代码嵌在 exe 内），
_internal\、data.db、backups\、logs\ 均无需改动。
